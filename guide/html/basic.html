4. 플랫폼 · 해상도 · 지원 환경

구현 형태하이브리드 앱 웹뷰 가정 (PRD Q-25 미정). 산출물은 HTML · CSS · 최소한의 JS입니다.
지원 환경iOS 15 이상 · Android 10 이상 (PRD A 4.5)
화면 구성모바일 전용 · 단일 마크업 (www/css/responsive.css)
기준 해상도시안 390 × 844 · 최소 지원 폭 360
· 360~480px = 폭 100% 유동
· 480px 초과 = 480 고정 · 가운데 정렬 (태블릿 · PC에서도 모바일 화면 그대로)
· 확인 폭: 360 · 390 · 430 · 480
안전 영역viewport-fit=cover + env(safe-area-inset-*)로 상단 상태 표시줄 · 하단 홈 표시줄을 피합니다.
글꼴Pretendard 공식 웹 배포 파일을 로컬로 넣었습니다(www/fonts, OFL 라이선스 동봉). 정적 서브셋 woff2 4개 — Pretendard-Regular · Medium · SemiBold · Bold.subset.woff2(각 약 270KB, 굵기 400 · 500 · 600 · 700). 한글 KS X 1001 2,350자 + 영문 · 숫자 · 기호이며, 그 밖의 글자는 시스템 글꼴로 표시됩니다. 외부 CDN 의존은 없습니다. 웹에는 .otf 대신 압축된 .woff2를 씁니다.

5. 코딩 규칙

클래스 접두사cs- · ui- 디자인 시스템 (고치지 않음) / mo- 화면 전용 (app.css) / is- · has- 상태. 이 밖의 클래스는 빌드 검사에서 막힙니다.
색 · 간격 · 반경모두 토큰 var(--cs-*)만 씁니다. app.css에 직접 쓴 색(#hex · rgb)과 px 반경은 없습니다.
아이콘<svg class="cs-icon" aria-hidden="true"><use href="#cs-i-이름"/></svg> — 아이콘 목록 페이지 참고
접근성모든 button에 type, 이미지에 alt, 장식 아이콘 aria-hidden, 상태는 aria-checked · aria-selected · aria-current · aria-pressed로 함께 표시합니다. 화면 제목(h1)은 낭독용으로 숨겨 둔 화면이 있습니다(cs-sr-only).
아직 없는 화면링크에 data-todo가 붙어 있고, 누르면 「준비 중」 알림이 뜹니다. 개발 때 실제 경로로 바꿉니다.
