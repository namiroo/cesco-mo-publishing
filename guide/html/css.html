CSS · 토큰

1. 파일 구성 · 불러오는 순서

1. font.cssPretendard 등록 — 공식 pretendard-subset.css와 같은 형식, 굵기 400 · 500 · 600 · 700 (../fonts/)
2. cesco-ui.css디자인 시스템 — 토큰(--cs-*) · 초기화 · 공통 부품(ui-*) · 아이콘 크기(cs-icon). 공통 부품의 모양 · 변형 · 마크업은 왼쪽 DESIGN SYSTEM 문서(Styles · 화면에 쓰인 Components)에서 봅니다.
공통 수정버튼 · 입력칸 · 하단 탭 같은 공통 부품을 바꿀 때는 cesco-ui.css의 해당 부품(또는 토큰) 한 곳만 고칩니다. 모든 화면에 한 번에 반영됩니다. 화면별로 덮어쓰지 말고, 바꾼 내용은 디자인 팀에 공유해 디자인 시스템 정본과 Figma에도 맞춥니다.
3. app.css화면 전용 스타일(mo-*) — 디자인에서 확정한 값입니다. 부품 모양을 화면에 맞게 덮는 규칙도 여기에 있습니다.
4. responsive.css화면 폭 — 360~480 유동, 480 초과 시 480 고정 · 가운데.

2. 규칙

  • 값은 토큰으로만 씁니다. 색은 의미 토큰(--cs-text-* · --cs-surface-* · --cs-border-* · --cs-icon-* · --cs-fill-*)을 먼저 쓰고, 상태 색처럼 의미 토큰이 없을 때만 팔레트(--cs-blue-500 등)를 씁니다.
  • 글자 크기 기준은 브라우저 기본(16px = 1rem)입니다. 시스템 글자 크기 설정을 따라 커집니다.
  • 상태는 클래스 is-*와 aria 속성으로 바꿉니다. 스타일을 인라인으로 넣지 않습니다(진행 막대 위치 같은 수치 변수만 예외).
  • 움직임 줄이기 설정(prefers-reduced-motion)에서는 애니메이션을 끕니다.
