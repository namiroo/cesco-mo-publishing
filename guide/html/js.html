app.js 동작

1. 원칙

  • 스크립트는 세 개, 외부 라이브러리 없음: app.js 화면 동작 · data.js 데이터 계층 · render.js 데이터 → 화면(데이터 화면만 불러옴). 아래 목록은 app.js입니다.
  • app.js는 화면이 바로 보이도록 모양 · 상태 전환만 담당합니다.
  • 상태는 클래스(is-on · is-active · is-stuck 등)와 aria 속성으로만 바꿉니다. 개발 프레임워크로 옮길 때 같은 클래스 · 속성을 상태 값에 연결하면 됩니다.
  • app.js는 데이터를 다루지 않습니다. 조회와 화면 갱신은 data.js · render.js가 맡고, 저장 · 로그인 검증 API 연결이 개발에서 붙일 자리입니다 — 데이터 명세 · 화면 상태 페이지 참고.
  • 동작을 거는 표시는 data-* 속성입니다(예: data-edit · data-read-all · data-toast). 클래스 이름을 바꿔도 동작이 깨지지 않습니다.
