1. 기본 틀

모든 화면 HTML은 같은 틀을 씁니다. 화면마다 바뀌는 것은 제목 · 상단 색(theme-color) · 본문뿐입니다.

<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<meta name="theme-color" content="#FFFFFF">
<title>화면 이름 | 화면 ID | 세스코 모바일 오피스</title>
<link rel="stylesheet" href="{font}">
<link rel="stylesheet" href="../css/cesco-ui.css">
<link rel="stylesheet" href="../css/app.css">
<link rel="stylesheet" href="../css/responsive.css">
<script src="../js/icons.js"></script>
</head>
<body class="mo-page">
<!-- 화면ID 화면 이름 · 생성물 — 원본 03_디자인/screens/화면ID.html 을 고친 뒤 python3 tools/build.py -->
<div class="mo-app">
  … 화면 본문 …
</div>
<div class="mo-toast" aria-live="polite"><div class="ui-toast ui-toast--success" role="status"><svg class="cs-icon ui-toast__icon" aria-hidden="true"><use href="#cs-i-check"/></svg><span></span></div></div>
<script src="../js/app.js"></script>
<!-- 데이터 화면만: ../data/mock.js · ../js/data.js · ../js/render.js -->
</body>
</html>

2. 영역

선택자역할
body.mo-page모든 화면의 바탕. 글자 크기 기준 16px
.mo-app화면 틀. 최대 폭 480 · 가운데 정렬 · 높이 100dvh
.mo-top상단 고정 영역(있는 화면만). 스크롤되면 is-stuck
.mo-bottom > .ui-bnav하단 탭(탭이 있는 화면만). 선택 탭 is-active + aria-current="page"
.mo-toast알림 띠 자리. data-toast="문구"가 붙은 버튼을 누르면 나타남
